# Torre del Eclipse

Proyecto individual de **Iñaki Bertran** para Programación de Videojuegos II y Audio y Sonido para Videojuegos.

## Experiencia

Juego de acción 3D con cámara superior. Un mago despeja la planta baja de una torre, recoge y utiliza pociones y asciende a la terraza para enfrentar a un jefe. Dispone de proyectiles mágicos y un ataque cuerpo a cuerpo con bastón.

## Herramientas

- Unity **6000.3.10f1**, Universal Render Pipeline **17.3.0**.
- Input System **1.18.0**.
- FMOD Studio **2.04.00**; integración para Unity de la misma rama 2.04.
- Reaper para edición, producción y mezcla de audio.
- Git y GitHub para historial del desarrollo.

## Estado

Hito 0 en curso. El proyecto de Unity y su primer commit existen. Esta documentación registra el alcance y las tareas iniciales; no implica que la jugabilidad o la integración de audio estén terminadas.

## Organización prevista

- `Assets`, `Packages` y `ProjectSettings`: proyecto Unity.
- `Docs`: concepto, tareas y registro de fuentes.
- `Audio/Fuentes`: audios de trabajo.
- `Audio/Reaper`: sesiones de edición, a crear al comenzar la producción sonora.
- `Audio/FMOD`: proyecto completo de FMOD.

## Hitos y entregas

Primero se completa Hito 0; luego core gameplay, vertical slice, producción, feature complete y release. La preparación de audio avanza en paralelo para una primera muestra el 13/11/2026. Entrega final de ambas materias: 20/11/2026.

## Alcance

La base incluye un mago, un nivel con planta baja y terraza, ambos tipos de combate, pociones, enemigos, jefe, menús, audio adaptativo y victoria/derrota con reinicio. La vara secreta y su acertijo son ampliaciones; guerrero y arquero quedan para después de completar y probar la base.
