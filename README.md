# Torre del Eclipse

Proyecto individual de **Iñaki Bertran** para **Programación de Videojuegos II** y **Audio y Sonido para Videojuegos**. Entrega final del **20/11/2026**.

Juego de acción 3D de fantasía oscura con cámara superior. Un mago debe despejar la planta baja de la torre y ascender a la terraza para derrotar al Custodio del Eclipse. El combate combina magia, golpes de bastón, esquives y pociones, con un jefe de dos fases y un punto de reintento en la terraza.

Desarrollado en **Unity 6000.3.10f1** con audio adaptativo en **FMOD Studio 2.04.00**. El ambiente cambia entre el interior y la terraza, y la música responde al combate y a las fases del jefe.

## Escenas

- [MenuPrincipal.unity](Assets/Scenes/MenuPrincipal.unity) es el punto de entrada del juego.
- [TorreEclipse.unity](Assets/Scenes/TorreEclipse.unity) contiene el nivel final, con la planta baja y la terraza del jefe.

## Controles

| Entrada | Acción |
| --- | --- |
| WASD | Moverse |
| Mouse | Apuntar |
| Clic izquierdo | Lanzar magia |
| Clic derecho | Golpear con el bastón |
| Espacio | Esquivar |
| E | Recoger pociones o usar la escalera |
| Q | Consumir una poción |
| Esc | Pausar o volver en los menús |
| R | Reiniciar el nivel o reintentar tras la derrota |

## Estado de la entrega
